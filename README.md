# Faith Rwams AFH Website

A responsive static website for Faith Rwams AFH in Federal Way, Washington.

## Files
- `index.html` — the complete website
- `images/` — the supplied home photographs

## Publish with GitHub Pages
1. Create a new GitHub repository (for example: `faith-rwams-afh`).
2. Upload `index.html` and the entire `images` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will give you the public website address.

## Important
The website uses the public contact information supplied for the project. It intentionally lists only **Federal Way, WA** rather than a street address.
Before publishing, verify the wording of services, licensing/registration information, and any claims about care against the home's current Washington requirements.
